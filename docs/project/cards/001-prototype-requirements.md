# [CARD-001] 모바일 웹 최적화 지하철 엘리베이터 & AI 출발 안내 프로토타입 요구사항 정의

- **작업 레벨**: Standard
- **상태**: 요구사항 갱신 완료 (Updated based on user feedback)
- **작성일**: 2026-10-28

---

## 1. 요구 요약 (3줄 이내)
1. 외부 백엔드/빌드 도구 없이 **순수 HTML, CSS, JavaScript와 하드코딩된 목업 데이터**만으로 동작하는 웹 프로토타입을 제작한다.
2. **모바일 웹 GUI에 최적화된 반응형 UI** 위에서 수도권 **모든 노선을 시각화**하고, 2호선 및 주요 환승역의 엘리베이터 상태(이용가능/불가)와 대체역 안내를 제공한다.
3. 열차 시간과 이동 시간을 고려한 **출발 시각 계산기** 및 자연어로 엘리베이터 상태와 경로를 안내하는 **AI Agent 챗봇**을 구현한다.

---

## 2. 변경 및 구체화된 핵심 요구사항

### F1. 기술 스택 및 구동 환경
- **순수 웹 기술**: HTML5, Vanilla CSS3 (현대적 디자인 시스템 적용), Vanilla JavaScript (ES6+).
- **무설치·무빌드**: 별도의 Node.js 서버나 npm 빌드 과정 없이, 브라우저에서 `index.html`을 열거나 정적 웹 호스팅으로 즉시 실행 가능.
- **하드코딩 목업 데이터**:
  - 수도권 전체 주요 노선 구조 (1~9호선, 수인분당선, 신분당선, 경의중앙선, 공항철도 등 주요 노선도 맵 좌표 및 연결 데이터)
  - 2호선 및 핵심 환승역들의 상세 엘리베이터 상태 (출구 번호, 승강장 위치, 작동 여부, 점검 사유)
  - 열차 시간표/배차 간격 및 역간 소요 시간 데이터

### F2. 모바일 웹 GUI 최적화 (Mobile-First UX)
- **모바일 뷰포트 최적화**: 390px~430px 기준 모바일 스마트폰 화면에 완벽 최적화 (데스크톱에서는 세련된 모바일 디바이스 목업 프레임 또는 풀스크린 모바일 모드 선택 가능).
- **하단 바텀 시트 (Bottom Sheet)**: 역 터치 시 부드럽게 올라와 엘리베이터 상태, 대체역, 출발 시간 추천 카드를 표시.
- **하단 탭 네비게이션**: [노선도 뷰], [엘리베이터 상태], [출발 시각 계산], [AI 챗봇] 전환 가능.
- **터치 친화적 인터랙션**: 핀치 줌/팬(Pan/Zoom) 지원 인터랙티브 노선도, 원터치 엘리베이터 상태 토글 (데모 시연용 고장 전환 버튼).

### F3. 수도권 모든 노선 시각화 (Metro Map Visualization)
- 수도권 지하철의 시각적 웅장함을 살린 **전체 노선도 인터랙티브 뷰 (SVG 기반 인터랙티브 메트로 맵)**.
- 1호선~9호선, 공항철도, 신분당선, 수인분당선 등 고유 공식 노선 컬러 적용.
- 2호선 루프 및 주요 환승 결절점을 강조하여, 역 클릭 시 실시간 엘리베이터 상태 배지(초록: 정상, 빨강: 점검) 표시.

### F4. 엘리베이터 상태 & 대체역 우회 안내
- 특정 역의 엘리베이터가 고장(`UNAVAILABLE`)일 때:
  - 인접 역 중 엘리베이터가 정상인 가장 가까운 역을 '추천 대체역'으로 시각적 하이라이트.
  - 대체역에서 원래 목적지까지의 도보/버스 환승 팁 및 거리 안내.

### F5. 출발 시각 역산 계산기 (Departure Time Assistant)
- 출발역, 도착역, 목표 도착 시각(또는 실시간 가장 빠른 출발) 선택.
- `(목표 시각) - (도보 7분 + 역사 진입/엘리베이터 3분 + 열차 이동 N분)`을 계산하여 "몇 시 몇 분 출발 권장" 안내.

### F6. 클라이언트 기반 AI Agent 챗봇
- 모바일 채팅창 인터페이스.
- 자연어 질의 파싱 (예: "강남역 엘리베이터 지금 돼?", "시청역 고장났는데 어디로 가야 해?", "잠실역 3시까지 가려면 언제 출발해?").
- 키워드 및 인텐트 기반 자동 도구 호출(Tool Calling) 시뮬레이션으로 정확한 데이터 기반 카드형 답변 제공.
