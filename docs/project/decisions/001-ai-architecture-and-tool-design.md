# [DECISION-001] AI 파트 아키텍처 및 도구 통합 설계 결정

- **작성일**: 2026-11-11
- **결정자**: AI 파트 (참조: `AI/docs/DESIGN_REVIEW.md`, `CARD-004`)

## 결정 사항
1. **역할 분리**: "LLM은 해석(의도/슬롯)과 자연어 설명만 수행하고, 백엔드가 경로/시간 계산 및 UI 액션 데이터를 직접 조립"한다.
2. **도구 통합**: 기존 5개 도구를 4개(`resolve_station`, `get_elevator_status`, `get_broken_elevators`, `plan_trip`)로 재정의하여 중복과 출발역 누락 결함을 해소한다.
3. **보수적 시간 역산**: 평균 대기시간이 아닌 배차간격 전체와 안전 마진을 반영하여 교통약자가 지각하지 않도록 보장한다.
4. **이중 안전장치**: 도구 강제(`tool_choice`)와 후처리 검증(Guard)을 도입하고, 타임아웃/장애 시 프로토타입 룰 기반 엔진으로 즉각 폴백한다.

## 이유 및 기대 효과
- LLM이 임의로 시간이나 역명을 생성하는 환각(Hallucination) 위험을 원천 차단하고, 외부 LLM API 장애 시에도 서비스가 중단되지 않는 견고성을 확보한다.
